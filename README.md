# IoT Sensor Telemetry & Embedded Systems

This repository contains firmware code and documentation developed for the **Upskill Campus** IoT and Embedded Systems program. It focuses on real-time sensor data collection, processing, and telemetry routing.

---

## 📌 Repository Contents

| File / Folder | Description |
| :--- | :--- |
| `IoT_Sensor_Telemetry.cpp` | C++ firmware implementation for sensor telemetry and data acquisition. |
| `IoT_Embedded_Abhishek_USC_UCT.pdf` | Documentation, project reports, or submission certificate for Upskill Campus. |

---

## 🚀 Key Features

* **Real-time Telemetry:** Reads sensor metrics and serializes data for transmission.
* **Embedded Processing:** Non-blocking C++ loops for low-latency processing.
* **Modular Structure:** Easy to adapt for microcontrollers like ESP32, ESP8266, or STM32.

---

## 🛠 Hardware & Requirements

* **Microcontroller:** ESP32 / ESP8266 / STM32
* **Language:** C++ / Arduino Framework
* **IDE Tools:** VS Code (PlatformIO) or Arduino IDE
